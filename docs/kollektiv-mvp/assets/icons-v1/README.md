# My House illustrated icons — first pass

Generated with the built-in imagegen tool on 14 September 2026, using the approved Our house board as a style reference.

| PNG master | Intended use |
| --- | --- |
| [house.png](house.png) | House navigation illustration |
| [meals.png](meals.png) | Meals entrance and dinner cards |
| [chores.png](chores.png) | Chores entrance and task cards |
| [calendar.png](calendar.png) | Plans entrance and week illustrations |
| [chat.png](chat.png) | Group-chat entrance and empty state |
| [agent.png](agent.png) | House agent avatar |

All six files are 1254 × 1254 PNGs with actual transparent pixels, checked using ImageIO/CoreGraphics. Generated originals were copied unchanged; no background removal, resizing or retouching was performed. The source outputs remain preserved.

[Preview gallery](index.html) displays the assets on yellow and white surfaces at large size and at 32, 64 and 128 CSS pixels. The browser tool blocked opening this local preview, so small-size browser verification is still pending. Large generated outputs were visually inspected. Some soft shading and edge irregularities remain; these are first-pass illustration masters, not certified production exports.

Use the colourful artwork for navigation illustrations, cards and the agent avatar. Keep native monochrome symbols for very small tab-bar and action controls until small-size legibility is verified. These are not an iOS App Store app-icon asset catalog.

Exact final prompts: [prompts.json](prompts.json). Original generated filenames: [sources.json](sources.json). No app integration has been performed.
